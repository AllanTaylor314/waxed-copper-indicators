**Waxed Copper Indicators** is a lightweight, vanilla-friendly resource pack that adds a small honeycomb badge to the corner of waxed copper items in the GUI (inventory, chests, recipes). Held and placed blocks retain their original appearance.

> **Version Note:** This pack requires **Minecraft 1.21.4 or newer** since it utilizes the new item model to dynamically overlay the badge.

This pack references the game's current honeycomb texture. If you are using a custom resource pack, the badge will automatically adapt and match that pack's style.
